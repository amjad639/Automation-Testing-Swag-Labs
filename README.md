# Selenium Automation Framework - Swag Labs

## 📌 Project Overview

This project is a Selenium WebDriver automation framework developed to automate the main functionalities of the **Swag Labs** website.

The framework follows the **Page Object Model (POM)** design pattern and uses **TestNG** for test execution and assertions.

The main purpose of this project is to automate login scenarios and verify inventory page elements after successful login.

---

## 🛠️ Technologies Used

- Java 17
- Selenium WebDriver 4
- TestNG
- Maven
- Page Object Model (POM)
- Allure Reporting
- JSON Data Driven Testing
- WebDriverWait (Explicit Wait)
